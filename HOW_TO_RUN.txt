## macOS – How to Run Snowgun

macOS includes security protections that block applications downloaded from the internet if they are not signed by Apple.  
Since **Snowgun is an indie, open-source project**, you need to manually allow it the first time you run it.

This process is **safe**, **common for indie software**, and only needs to be done **once**.
---

### 1. Open the Snowgun folder in Terminal
_________________________________________________________________

1. Open **Finder**
2. Navigate to the folder where you extracted `snowgun-macos-<version>`
3. Right-click inside the folder
4. Select “Open in Terminal” or "New Terminal at Folder" from the dropdown menu.

> This opens Terminal already positioned in the correct directory.
---



### 2. Remove macOS quarantine (required once)#######################
_________________________________________________________________

In the Terminal window that opens, run:
(Copy and paste the line in between the '%')


%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

sudo xattr -dr com.apple.quarantine .

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%


You will be prompted for your macOS user _PASSWORD_
No characters will appear while typing — this is normal
Press Enter to confirm.

macOS automatically marks downloaded applications as quarantined.
This command tells macOS that you trust these files.

This command does _NOT_:
- Access the internet
- Install software
- Modify system files
- Collect any data

It only removes a security flag from the Snowgun folder.
---



### 3. Launch the game ########################################
_________________________________________________________________

After the command completes:
- Close Terminal
- Double-click the snowgun executable

The game should now launch normally. ENJOY!
